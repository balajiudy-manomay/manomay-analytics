# Manomay Analytics - Power BI Dashboard Viewer

A Next.js app for embedding, viewing, and configuring Power BI dashboard reports.

## Run Locally

**Prerequisites:** Node.js 20+

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and set `NEXT_PUBLIC_POWERBI_EMBED_URL` to your Power BI embed URL.
3. Run the dev server:
   `npm run dev`

## Build

```bash
npm run build
npm start
```
